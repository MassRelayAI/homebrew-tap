# homebrew-tap

The Homebrew tap for massrelay-ai's open-source tools. Today: [CompareGraph](https://github.com/massrelay-ai/comparegraph).

```bash
brew install massrelay-ai/tap/comparegraph
```

Each formula follows the latest release on its own: a workflow here reads the release's `SHA256SUMS` every six hours, and
on demand, and rewrites the version, the urls and the sums. Nothing in it is edited by hand. Report problems in the main
repository.
