# homebrew-comparegraph

The Homebrew tap for [CompareGraph](https://github.com/massrelay-ai/comparegraph).

```bash
brew install massrelay-ai/comparegraph/comparegraph
```

The formula follows the latest release on its own: a workflow here reads the release's `SHA256SUMS` every six hours, and
on demand, and rewrites the version, the urls and the sums. Nothing in it is edited by hand. Report problems in the main
repository.
